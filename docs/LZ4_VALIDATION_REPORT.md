## 📊 성능 측정 결과

### 테스트 환경
- **시스템**: Apple Silicon (M1/M2 계열)
- **빌드**: Release (-O3)

- **데이터 크기**: 50KB ~ 1MB

### 압축 형식별 성능

#### Block 형식 (Native LZ4)

##### Text Data (~100KB, 매우 반복적)
```
레벨   압축 MB/s      해제 MB/s      압축률
L1     10,617         35,559         0.72%
L3     11,469         42,047         0.72%
L6      1,059         11,685         0.72%
L9      1,047         41,065         0.72%
```

**분석**:
- L1-L3: 매우 빠른 압축 (10K+ MB/s)
- L6-L9: 합리적인 속도 (1K MB/s)
- 모든 레벨에서 동일한 압축률 (텍스트가 작기 때문)
- 해제는 일관되게 빠름 (10K+ MB/s)

##### Zeros (1MB, 최적 시나리오)
```
레벨   압축 MB/s      해제 MB/s      압축률
L1     29,921         23,863         0.39%
L3     23,477         39,443         0.39%
L6        784         37,032         0.39%
L9        892         39,724         0.39%
```

**분석**:
- L1에서 매우 빠른 압축 (30K MB/s - 최고 성능)
- 모든 레벨에서 0.39% 압축률 (우수)
- 해제가 충분히 빠름 (24K+ MB/s)

##### Random (1MB, 최악 시나리오)
```
레벨   압축 MB/s      해제 MB/s      압축률
L1         90         31,271       100.39%
L3         76         30,475       100.39%
L6         25         16,009       100.39%
L9         25         32,583       100.39%
```

**분석**:
- 예상대로 느린 압축 (25-90 MB/s)
- 압축 불가능 데이터임을 확인
- 약 0.39%의 오버헤드 (정상)
- 해제는 여전히 빠름 (16K+ MB/s)

##### JSON (~50KB, 실무 데이터)
```
레벨   압축 MB/s      해제 MB/s      압축률
L1      1,169         2,880        10.86%
L3        709         2,624        10.86%
L6         82         1,572         9.86%
L9         48         3,241         9.65%
```

**분석**:
- 구조화된 데이터에서 10% 정도 압축
- L6-L9에서 추가 압축 가능 (10.86% → 9.65%)
- 처리량은 합리적 수준 (48-1169 MB/s)

##### Pattern (256KB, 반복 패턴)
```
레벨   압축 MB/s      해제 MB/s      압축률
L1     14,748         37,570         0.78%
L3     19,162         38,037         0.78%
L6        890         19,476         0.78%
L9        853         36,656         0.78%
```

**분석**:
- 규칙적 패턴에서 우수한 압축 (0.78%)
- L1-L3의 높은 처리량 (14K-19K MB/s)
- L9에서도 합리적 성능 (853 MB/s)

#### Frame 형식 (LZ4 CLI 호환)

Frame 형식은 header/footer/checksum 오버헤드로 인해 약 2-3배 느림:

##### Text Data
```
레벨   압축 MB/s      해제 MB/s      압축률
L1      2,119         4,372         0.75%
L3      3,229         4,181         0.75%
L6        503         2,378         0.75%
L9        334         4,090         0.75%
```

**분석**:
- Block 형식 대비 약 2-5배 느림 (예상대로)
- Frame 헤더/체크섬 오버헤드 있음 (0.03% 추가)
- lz4 CLI 호환성 제공
